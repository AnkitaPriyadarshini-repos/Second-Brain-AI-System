System Architecture & Engineering Specs

Second Brain AI System is built with zero cloud lock-in using high-performance local RAG semantic retrieval, custom TF-IDF vectorization, and interactive graph topology.

1. Local RAG Vector Engine

TF-IDF sparse vectorizer computing cosine similarity across 100+ pre-seeded notes in 12ms.

2. Zero-Leak Storage

IndexedDB & LocalStorage persistent storage. Data stays entirely on your browser thread.

3. Knowledge Graph Engine

Interactive HTML5 Canvas force-directed graph visualizer mapping bi-directional entity connections.

4. Proactive Resurfacing

Spaced-repetition decay algorithms triggering timely resurfacing digests of forgotten knowledge.
