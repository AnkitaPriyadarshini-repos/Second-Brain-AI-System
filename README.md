## ✨ Key Features

| Feature | Description |
| :--- | :--- |
| 🌼 **Juno AI Thinking Partner** | Conversational grounded Q&A with 100+ source citations and zero hallucination. |
| ⚡ **Multi-Surface Capture Hub** | Instant note capture via Typing, Voice Memos, Web Clipper, OCR, and Email. |
| 🤖 **AI Agents Fleet** | Multi-agent suite for study guide generation, active recall quizzes, and synthesis. |
| 🕸️ **Mind Map & Graph** | Interactive 2D canvas mapping bi-directional note & entity connections. |
| 🔮 **Proactive Resurfacing** | Spaced-repetition algorithms bringing back forgotten research notes. |
| 🔒 **100% On-Device Privacy** | All vector embeddings and data thread processing stay strictly local. |

---

## 🛠️ Tech Stack

- **Core**: Vanilla JavaScript (ES6+), HTML5, CSS3 (Golden Yellow Design System)
- **Vector Engine**: TF-IDF Sparse Embeddings + Cosine Similarity Alignment
- **Storage**: IndexedDB & LocalStorage (100+ Pre-seeded Technical Notes)
- **Audio & Visuals**: Web Speech API, HTML5 Audio Overview & Force-Graph Canvas

## 🚀 Quick Start

### 1. Clone & Run Locally
```bash
# Clone the repository
git clone https://github.com/AnkitaPriyadarshini-repos/Second-Brain-AI-System.git
cd Second-Brain-AI-System

# Serve locally
npx serve . -l 3000
```
Open `http://localhost:3000` in your browser.

### 2. Run Test Suite
```bash
npm test
```
*Executes all 18 automated unit tests (RAG Engine, NLP, Storage, Resurfacing, and Telemetry).*
